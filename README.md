Elite Motors - Inventory Management System
A full-stack web application designed for luxury car dealerships to manage their inventory and track customer inquiries. This project was developed as part of the Industry Practices (FA2) curriculum.

🚀 Tech Stack
Backend: Java, Spring Boot, Spring Security

Frontend: HTML5, CSS3, JavaScript, Bootstrap 5

Database: H2 (In-memory)

Build Tool: Maven

✨ Key Features
Dynamic Inventory: View high-end vehicles with real-time price and category details.

Live Search: Filter cars instantly using a JavaScript-powered search bar.

Inquiry System: Customers can express interest via a lead-generation form.

Admin Dashboard: Secure login for administrators to manage inventory (CRUD) and view customer leads.

Security: Role-Based Access Control (RBAC) implemented via Spring Security.
